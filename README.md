# AI-Powered MPLADS Monitoring System

## Project Overview
The AI-Powered MPLADS Monitoring System is a web-based platform designed to improve transparency, accountability, and monitoring of projects under the Members of Parliament Local Area Development Scheme (MPLADS).

It helps administrators and reviewers monitor project progress, verify submitted evidence, and view project-related information through a centralized dashboard.

## Key Features
- Role-based login for Admin, Reviewer, and Public Viewer
- Project monitoring dashboard
- Project progress tracking
- Evidence submission and verification
- Analytics and monitoring insights
- Centralized project information

## Technology Stack

**Frontend:**
- HTML
- CSS
- JavaScript

**Backend:**
- Python
- FastAPI

**Database:**
- SQLite
- SQLAlchemy

## Project Structure
- `backend/` – Backend application and API logic
- `frontend/` – User interface files
- `requirements.txt` – Python dependencies
- `.gitignore` – Files excluded from Git tracking

## Installation and Setup

1. Download or clone the project repository.
2. Open the project folder in VS Code.
3. Create and activate a Python virtual environment.
4. Install dependencies:

   `pip install -r requirements.txt`

5. Run the backend using the project's configured startup command.

## Project Objective
To provide a centralized digital monitoring solution that supports better tracking, verification, and transparency in MPLADS project implementation.
